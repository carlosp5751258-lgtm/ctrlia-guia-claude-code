# Guía Claude Code en español: primeros capítulos (gratis)

Los primeros capítulos de la guía «Claude Code de cero a experto»: instalación, cómo pedir tareas y CLAUDE.md.

**Gratis y de código abierto (MIT).** Úsalo en tus proyectos y en los de tus clientes.

## Qué incluye

- Capítulo 0: antes de empezar
- Capítulo 1: instalación y primeros pasos
- Capítulo 2: cómo pedir tareas
- Capítulo 3: CLAUDE.md, la memoria de tu proyecto

## Instalación

```bash
git clone https://github.com/carlosp5751258-lgtm/ctrlia-guia-claude-code.git
# o léela directamente en GitHub: guia.md
```
